# Brasa da Rua

Uma hamburgueria de bairro, com sabor feito na hora e um cardápio para dar vontade de pedir. Este site apresenta a Brasa da Rua e acompanha o cliente desde a escolha do lanche até a sacola.

## O que dá para fazer

- Conhecer a hamburgueria e ver os itens do cardápio.
- Adicionar produtos à sacola e conferir o subtotal.
- Escolher entre entrega e retirada.
- Criar uma conta ou continuar sem entrar.

## Páginas

| Página | O que você encontra |
| --- | --- |
| `index.html` | Apresentação da casa e cardápio |
| `cadastro.html` | Formulário de cadastro |
| `login.html` | Login ou acesso como visitante |
| `pagamento.html` | Opções de entrega e resumo do pedido |

## Feito com

- HTML para o conteúdo das páginas
- CSS para o visual e a adaptação a diferentes telas
- JavaScript para a sacola e os formulários

## Como abrir

Não precisa instalar nada: abra o arquivo `index.html` no navegador e navegue pelo site.
